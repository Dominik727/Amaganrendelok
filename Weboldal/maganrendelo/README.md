# Magánrendelő

This is a private clinic web application built with Angular.

## How to run

1. Install dependencies:
   ```sh
   npm install
   ```
2. Start the development server:
   ```sh
   npx ng serve --open
   ```
   The app will be available at http://localhost:4200/

## Requirements
- Node.js (LTS recommended)
- npm
- Modern web browser
